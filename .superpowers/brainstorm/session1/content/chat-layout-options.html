How should the RAG Chat interface integrate with the Dashboard?

Select the layout that best fits the betting workflow.

A

Split Screen (Side-by-Side)

Dashboard on the left, Chat on the right. Best for deep analysis while looking at the odds.

B

Floating Widget / Modal

Dashboard is full width. A chat button opens a floating window on top of the content. Good for quick queries.

C

Dedicated "Analysis" View

Clicking a match completely switches the view to a dedicated Chat + Match Stats page.
